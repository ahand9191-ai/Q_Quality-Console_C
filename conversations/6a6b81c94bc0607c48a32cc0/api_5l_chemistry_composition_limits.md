## 3. Carbon Equivalent Formulas (PSL2)

### CE_IIW (International Institute of Welding)
**Used when C > 0.12%**
```
CE_IIW = C + Mn/6 + (Cr + Mo + V)/5 + (Ni + Cu)/15
```
**Maximum limit: 0.43%** (for most grades; agreed for X80Q and above)

### CE_PCM (IIW / Ito-Bessyo)
**Used when C ≤ 0.12%**
```
CE_PCM = C + Si/30 + (Mn + Cu + Cr)/20 + Ni/60 + Mo/15 + V/10 + 5B
```
**Maximum limit: 0.25%** (for most grades; 0.19–0.22% for sour service)

Note: Some sources write the formula as:
```
PCM = C + Si/30 + Mn/20 + Cu/20 + Ni/60 + Cr/20 + Mo/15 + V/10 + 5B
```
This is equivalent since (Mn + Cu + Cr)/20 = Mn/20 + Cu/20 + Cr/20.

## 6. NACE MR0175 / ISO 15156 — Sour Service Material Requirements

### Chemistry Limits (Carbon and Low-Alloy Steels):
| Element | NACE MR0175 Limit |
|---------|-------------------|
| Sulfur (S) | ≤ 0.002% (welded); ≤ 0.003% (seamless per API 5L Annex H) |
| Phosphorus (P) | ≤ 0.020% |
| Carbon (C) | ≤ 0.10% (typical for sour service) |

### Hardness Limits:
- **Maximum hardness: 22 HRC (≈250 HV10)** for most carbon and low-alloy steels
- Applies to base metal, HAZ, and weld metal

### Applicable Grades (per NACE MR0175):
- API 5L Grade B through X70 (PSL2 required, PSL1 NOT suitable for sour service)
- ASTM A53, A106 Gr B/A/C, A333 Gr 1 & 6
- API 5CT J55/K55 through T95

### NACE TM0284 — HIC Test Method:
- Standard test method for evaluating resistance to Hydrogen Induced Cracking (HIC)
- Test duration: up to 96 hours
- Mandatory for sour service pipe per API 5L Annex H
- Tests in NACE solution (H2S-saturated, pH ~2.7-3.0) or simulated service environment
- Acceptance criteria: CLR (Crack Length Ratio), CTR (Crack Thickness Ratio), CSR (Crack Sensitivity Ratio)

### SSC (Sulfide Stress Cracking) — NACE TM0177:
- Test method for SSC resistance
- Required for material qualification in sour service
- Combined stress + H2S environment

## 7. Summary of Key Findings

1. **PSL1 → PSL2 transition** tightens S from 0.030% to 0.015% (50% reduction) and P from 0.030% to 0.025% (17% reduction), adds Si limits, adds CE control (CE_IIW ≤ 0.43%, CE_PCM ≤ 0.25%), and requires impact testing + NDT.

2. **PSL2 → Sour Service (Annex H)** further tightens S to 0.003% (SMLS) or 0.002% (welded), P to 0.020%, reduces C (especially M-grades to 0.10%), lowers CE_PCM to 0.19-0.22%, mandates Ca/S ≥ 1.5, limits hardness to 250 HV10, and requires HIC/SSC testing.

3. **Delivery condition matters**: M (thermomechanical) grades have the lowest C (0.10-0.12%) for sour service, making them preferred for high-strength sour applications. Q (quenched & tempered) allows C up to 0.14-0.16%.

4. **CE_IIW** formula: C + Mn/6 + (Cr+Mo+V)/5 + (Ni+Cu)/15 — applies when C > 0.12%

5. **CE_PCM** formula: C + Si/30 + (Mn+Cu+Cr)/20 + Ni/60 + Mo/15 + V/10 + 5B — applies when C ≤ 0.12%

6. **Welded vs Seamless**: Welded pipe has stricter C limits (0.26 vs 0.28 for PSL1) and lower S limits for sour service (0.002% vs 0.003%).
